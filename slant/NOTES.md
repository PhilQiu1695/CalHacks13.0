# Slant: implementation notes

Exported from the live Mana app (`apps/slant/app`) on October 25, 2026.

## Architecture

Slant UI. New analyses and Re-analyze run on the slant-ext backend (/workspace/slant-extension, POST /v1/me/analyze + GET /v1/me/jobs/<id>, team only: owner and Editors, verified Firebase ID token in X-Slant-Id-Token) via useIngressUrl('slant-ext'): same pipeline as Slant for Chrome (yt-bias captions, Gemini transcription fallback, OpenAI gpt-6-astra with a strict JSON schema; records carry via 'app'; the backend adds the video to the person's feed). Since 2026-10-24 the page holds no AI access (its Mana router OpenAI/Gemini tokens and the yt-bias ingress link were removed so Slant can be made public safely; backend limits for the team: one running analysis per person, 2 at once overall, AI transcription up to 20 min, captions up to 90 min; no daily cap). The top-level geminiTranscript/runAnalysis/SYSTEM/SCHEMA remain as the source the backend's spec is extracted from. Scoring: political lean on the AllSides Media Bias Meter scale -6..+6, five 0-10 signals (commercial interest removed 2026-10-24), overall shown as 'Slant score'; verbatim quotes with segment numbers, verified client-side against the transcript, and quotes that cannot be found are hidden). Results lead with political lean plus its AllSides label (on the score rounded to 0.1, AllSides bands: <=-3 Left, <=-1 Lean Left, <1 Center, <3 Lean Right, else Right). Pasting an already-analyzed video opens the saved report; Re-analyze re-runs it. Shorts (/shorts/ URLs) get a height-capped 9:16 player and portrait oardefault.jpg thumbnails. State: app/analyses/<id> (report) and app/transcripts/<id>/snippets. The 'Disagree?' notes feature was removed on 2026-10-24 at Phil's request (no notes had been submitted; the flags nodes and their open per-user write grants were deleted; pre-removal code in app/backups). View-only visitors are detected with a no-op delete probe at analyses/_probe_<uid>: they can open saved analyses but cannot start new ones, and the app says why before any credits are spent. URL params: ?slant=<id> opens a report, ?slant=how the How Slant works page. Mana credits are billed to the owner, including for shared viewers. Chrome extension (2026-10-24): Apps › Slant for Chrome (apps/slant-extension) is the owner console; backend daemon 'slant-ext' (/workspace/slant-extension) reuses this app's prompt/schema/models (spec extracted from this code; owner route /v1/owner/spec/sync re-extracts), the yt-bias caption service and the Gemini fallback, and saves new analyses here in the same shape with additive fields via='chrome-extension' and analysisVersion. Its 'Analyze again' updates an existing record like Re-analyze. Editing this app's prompt or schema: run sync in the console. Feed history (2026-10-24, Phil's request): each signed-in person's analyzed videos are kept privately at <owner>/file-system/slant-feeds/<uid>/videos/<videoId> (score snapshot s via feedSnap, count, firstAt/lastAt, vias app|chrome-extension; per_user_read/write on slant-feeds, so Editors can't see each other's feeds). Recorded when a person pastes a link (new or already analyzed), on 'Add to my feed' on an analysis, from the feed page's library list, and by the slant-ext backend for browsers linked to a person (pairing code creator, or 'This is my browser' in the console). ?slant=feed is 'Your feed': period chips (30 days/3/6/12 months, capped by keepDays 91|182|365, default 365, pruned on open), dot plot on the lean axis (tap a dot for details, tap again to hide), echo chamber index 0-100 (40% one side dominates, 20% narrow off-centre range, 20% source concentration, 20% heat; needs 5 political videos; tap a signal for details), channels, months, signal averages, 'To widen your feed' suggestions from the library, and an AI detailed report (gpt-6-astra, FEED_SYSTEM/FEED_SCHEMA, about 36 s, owner's credits) saved at slant-feeds/<uid>/reports/<rid> (&report=<rid>).
